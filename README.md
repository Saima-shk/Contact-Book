Project Name: **Contact Book Application**

📌 Project Overview:
The Contact Book is a Python-based desktop application developed using Tkinter and SQLite.
It allows users to manage their contacts through a simple graphical user interface (GUI).
The application also integrates a public REST API to fetch and display sample contact data.

✨ Features:
1. Add Contact: Add new contacts with details such as name, phone number, and email.
2. View Contacts: Display saved contacts in the application.
3. Search Contact: Search for contacts easily.
4. Edit Contact: Update existing contact information.
5. Delete Contact: Remove unwanted contacts.
6. SQLite Database: Store contact details locally.
7. API Integration: Fetch and display sample user data from a public API.
8. User-Friendly GUI: Simple interface built with Tkinter.

🛠️ Technologies Used:
1. Python
2. Tkinter
3. SQLite
4. REST API
5. Requests Library
6. JSONPlaceholder API

🎯 Project Objective:
The objective of this project is to develop a simple contact management application while learning Python GUI development, database operations, REST API integration, and basic application testing.

🚀 Future Enhancements:
1. Add input validation for phone numbers and email addresses.
2. Improve the GUI design and styling.
3. Add contact import and export functionality.
