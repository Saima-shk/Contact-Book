Project Name: **Contact Book Application**

📌 Project Overview:
The Contact Book is a Python-based desktop application developed using Tkinter and SQLite.
It allows users to manage their contacts through a simple graphical user interface (GUI).
The application also integrates a public REST API to fetch and display sample contact data.

✨ Features:
Add Contact: Add new contacts with details such as name, phone number, and email.
View Contacts: Display saved contacts in the application.
Search Contact: Search for contacts easily.
Edit Contact: Update existing contact information.
Delete Contact: Remove unwanted contacts.
SQLite Database: Store contact details locally.
API Integration: Fetch and display sample user data from a public API.
User-Friendly GUI: Simple interface built with Tkinter.

🛠️ Technologies Used:
Python
Tkinter
SQLite
REST API
Requests Library
JSONPlaceholder API

🎯 Project Objective:
The objective of this project is to develop a simple contact management application while learning Python GUI development, database operations, REST API integration, and basic application testing.
